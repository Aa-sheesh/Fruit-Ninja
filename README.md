# 🍓 Fruit Ninja

A full-stack fruit ordering web app with a modern UI and dual database backend.

## 🚀 Live Links
- Frontend: [fruit-ninja-henna.vercel.app](https://fruit-ninja-henna.vercel.app)
- Backend API: [fruit-ninja-7tju.onrender.com](https://fruit-ninja-7tju.onrender.com)

## 🛠 Tech Stack
- **Frontend**: React, TypeScript, TailwindCSS
- **Backend**: Node.js, Express, MongoDB, PostgreSQL (Sequelize)

## 📦 Features
- Browse fruit bowls and drinks
- View bestsellers
- Place orders (stored in PostgreSQL)
- Fully responsive design

## ⚙️ Run Locally
```bash
# Backend
cd server && npm install && npm run dev

# Frontend
cd client && npm install && npm run dev
```
